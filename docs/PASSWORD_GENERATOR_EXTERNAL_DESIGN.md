## 1. 概要

### 1.1 目的
利用者が設定した長さと文字種に基づき、ブラウザー内でパスワードを生成してコピーする。

### 1.2 対象ページ
| 項目 | 内容 |
|------|------|
| ページ名 | Password Generator |
| URL | `https://password-generator.shinyaishizaki.com/` |
| 実装ページ | 独立リポジトリ `password-generator` の `index.html` |
| スタイル | 独立リポジトリの `styles.css` |
| クライアントスクリプト | 独立リポジトリの `password-generator.js` |
| 公開方式 | GitHub Pages（静的ファイル、GitHub Actionsでデプロイ） |
| オリジン | 公式サイト `https://shinyaishizaki.com` とは別オリジン |

## 2. 利用者と利用シナリオ

### 2.1 想定利用者
- Webサイト訪問者
- その他: 未記入

### 2.2 基本シナリオ
1. 公式サイトのProjectsページから外部のジェネレーターを開く。
2. パスワード長と含める文字種を指定する。
3. 「Generate password」を実行する。
4. 結果を確認し、「Copy」でコピーする。
5. ページ上のステータス通知で処理結果を確認する。

## 3. 画面構成

| 領域 | 表示要素 | 初期状態・仕様 |
|------|----------|----------------|
| 長さ | 数値入力、範囲案内 | 初期値20、最小8、最大128 |
| 文字種 | 小文字、大文字、数字、記号 | 初期状態はすべて選択 |
| 生成操作 | Generate passwordボタン | フォーム送信として実行 |
| 結果 | 読み取り専用テキスト入力 | 未生成時はプレースホルダーを表示 |
| コピー操作 | Copyボタン | 結果がない間は無効 |
| 状態通知 | ライブリージョン | 生成、コピー、入力エラー等を通知 |
| プライバシー表示 | ローカル生成の説明 | 生成値をサーバーへ送信しない旨を表示 |

## 4. 画面項目・入力仕様

| 項目 | 入力形式 | 必須 | 許容値／初期値 | エラー時の扱い |
|------|----------|------|----------------|----------------|
| 長さ | 数値 | 必須 | 整数8～128／20 | 生成を中止し、ステータスを表示 |
| 小文字 | チェックボックス | 文字種全体で必須 | 選択／初期選択 | なし |
| 大文字 | チェックボックス | 文字種全体で必須 | 選択／初期選択 | なし |
| 数字 | チェックボックス | 文字種全体で必須 | 選択／初期選択 | なし |
| 記号 | チェックボックス | 文字種全体で必須 | 選択／初期選択 | なし |
| 結果 | 読み取り専用テキスト | なし | 生成値 | 生成前・生成失敗時は空欄 |

記号セット（現行実装）: `!@#$%^&*()-_=+[]{};:,.?`

## 5. 操作・応答仕様

| 操作 | 条件 | 画面応答 |
|------|------|----------|
| 生成 | 長さが範囲内かつ文字種を1つ以上選択 | 結果欄を更新し、コピーを有効化、成功状態を通知 |
| 生成 | 長さが不正 | 結果欄をクリアし、コピーを無効化、長さエラーを通知 |
| 生成 | 文字種未選択 | 結果欄をクリアし、コピーを無効化、選択エラーを通知 |
| 生成 | 安全な乱数APIが利用不可 | 結果欄をクリアし、コピーを無効化、利用不可を通知 |
| コピー | 結果あり、Clipboard API成功 | クリップボードへ書き込み、成功を通知 |
| コピー | Clipboard API失敗 | 結果を選択状態にし、手動コピーを案内 |

## 6. 外部インターフェース

| インターフェース | 用途 | データ／失敗時の扱い |
|------------------|------|----------------------|
| `window.crypto.getRandomValues` | 生成用の安全な乱数取得 | 利用不可なら生成しない |
| `navigator.clipboard.writeText` | 生成結果のコピー | 拒否・失敗時は手動コピーを案内 |
| サーバー通信 | GitHub Pagesから静的ファイルを取得 | 生成値を送信しない。外部通信・第三者スクリプトを追加しない |

## 7. 表示・アクセシビリティ方針
- すべての入力にラベルを関連付ける。
- 文字種選択はグループ名を持つフィールドセットとして扱う。
- ステータス通知は `role="status"` と `aria-live="polite"` を利用する。
- キーボードで入力、生成、コピー操作ができること。
- レスポンシブ時のレイアウトとフォーカス表示は実機・ブラウザーで確認する。
