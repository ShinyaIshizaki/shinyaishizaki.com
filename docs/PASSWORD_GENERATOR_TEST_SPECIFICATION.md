## 1. テスト概要

### 1.1 目的
機能要件、入力境界、安全な乱数利用、コピー、アクセシビリティ、および生成値のプライバシー要件を検証する。

### 1.2 対象範囲
- パスワード長と文字種の入力
- 生成結果の長さ・文字種構成
- 乱数API利用不可時の動作
- クリップボード成功・失敗時の動作
- 状態通知、キーボード操作、レスポンシブ表示
- ネットワーク送信・永続保存の有無

### 1.3 対象外
- パスワードの強度評価（要件に追加された場合は追記）
- 未記入: その他の対象外

## 3. 前提・テストデータ
- JavaScriptが有効であること。
- クリップボードの正常系は、Clipboard APIが許可される安全なコンテキストで実施する。
- 不正な長さのテストでは、HTML標準の制約検証とアプリケーション側の検証を区別して記録する。
- 生成値はテスト結果、スクリーンショット、ログに記録しない。必要な場合は値を伏せる。
- その他: 未記入
