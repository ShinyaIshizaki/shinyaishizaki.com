## 1. 背景・目的

### 1.1 背景

エンジニアリングスキル向上のため、パスワードジェネレーターを自作したい。

### 1.2 目的

利用者が設定した長さと文字種に基づき、ブラウザー内でパスワードを生成してコピーする。

### 1.3 成功条件

* [ ] 利用者が指定した長さと文字種でパスワードを生成できる

* [ ] 生成した値をクリップボードへコピーできる

* [ ] 生成処理でパスワードをサーバーへ送信・保存しない

## 2. 対象範囲

### 2.1 対象に含む

* パスワード長の指定（現行実装: 8～128文字、初期値20文字）

* 小文字・大文字・数字・記号の文字種選択

* パスワード生成、結果表示、コピー

* 入力不備およびブラウザー機能利用不可時の通知

### 2.2 対象外

* アカウント認証、生成履歴、生成値のサーバー保存

* パスワード強度の保証・評価（必要な場合は要件を追加する）

## 3. 利用者・利用環境

| 項目      | 内容                                                              |
| ------- | --------------------------------------------------------------- |
| 主な利用者   | Webサイト訪問者                                                       |
| 利用端末    | デスクトップ、タブレット、スマートフォン                                            |
| 対応ブラウザー | Google Chrome安定版の最新メジャーバージョンおよび1つ前のメジャーバージョン。テスト実施時のバージョンを記録する。 |
| 利用条件    | JavaScriptおよび安全な乱数APIが利用可能であること                                 |

## 4. 機能要件

| ID    | 要件                            | 優先度 | 受入条件                            |
| ----- | ----------------------------- | --- | ------------------------------- |
| FR-01 | 利用者が生成するパスワードの長さを指定できる        | 必須  | 8～128の整数を受け付け、範囲外・整数以外は生成せず通知する |
| FR-02 | 小文字、大文字、数字、記号を個別に選択できる        | 必須  | 1種類以上選択されていない場合は生成せず通知する        |
| FR-03 | 選択した各文字種を少なくとも1文字含むパスワードを生成する | 必須  | 全選択文字種が結果に含まれ、指定長と一致する          |
| FR-04 | 生成結果を読み取り専用の入力欄に表示する          | 必須  | 生成後に結果が確認できる                    |
| FR-05 | 生成結果をクリップボードへコピーできる           | 必須  | コピー成功・失敗が利用者に通知される              |
| FR-06 | 生成・コピーの状態とエラーを支援技術にも通知する      | 必須  | ステータス領域が適切に読み上げられる              |

## 5. 非機能要件

| ID     | 分類       | 要件                    | 指標・受入条件                                    |
| ------ | -------- | --------------------- | ------------------------------------------ |
| NFR-01 | セキュリティ   | 暗号学的に安全な乱数を用いる        | `crypto.getRandomValues` が使用され、利用不可時は生成しない |
| NFR-02 | プライバシー   | 生成値をネットワーク送信・永続保存しない  | 通信・保存処理がないことを確認する                          |
| NFR-03 | アクセシビリティ | ラベル、キーボード操作、状態通知を提供する | 手動確認および必要な自動検査を実施する                        |
| NFR-04 | 互換性      | 対象ブラウザーで生成・コピーできる     | 対象ブラウザー一覧と確認結果を記録する                        |
| NFR-05 | 保守性      | 文字種・制約・エラー文言を追跡可能にする  | 設計書と実装の差分をレビューする                           |

## 6. 入力・出力

| データ    | 入力元／出力先  | 制約・説明                |
| ------ | -------- | -------------------- |
| パスワード長 | 利用者入力    | 整数、8～128（現行実装）       |
| 文字種    | チェックボックス | 小文字、大文字、数字、記号（現行実装）  |
| 生成結果   | 結果表示欄    | ブラウザー内で生成し、利用者操作でコピー |

## 7. 制約・前提

* 公開先はJekyllサイト内の `/tools/password-generator/` とする。

* JavaScriptが無効の場合、ジェネレーター機能は利用できない。

* 乱数APIやクリップボードAPIの利用可否はブラウザーおよび実行コンテキストに依存する。

## 8. 受入テスト観点

* [ ] 最小値8、最大値128で生成できる

* [ ] 7、129、小数、空欄など不正な長さで生成されない

* [ ] 文字種未選択時に生成されず、説明が通知される

* [ ] 選択した文字種をすべて含み、長さが一致する

* [ ] 乱数APIが使えない場合に安全側に失敗する

* [ ] コピー成功とコピー失敗の両方を確認する

* [ ] モバイル幅、キーボード操作、読み上げ状態を確認する

* [ ] 生成値がサーバーへ送信・保存されないことを確認する
