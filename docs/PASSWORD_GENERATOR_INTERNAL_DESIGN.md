## 2. データ定義

| 名前 | 内容 |
|------|------|
| `characterSets.lowercase` | `abcdefghijklmnopqrstuvwxyz` |
| `characterSets.uppercase` | `ABCDEFGHIJKLMNOPQRSTUVWXYZ` |
| `characterSets.numbers` | `0123456789` |
| `characterSets.symbols` | `!@#$%^&*()-_=+[]{};:,.?` |
| 長さ | `Number` に変換後、整数かつ8～128であることを検証 |
| 選択セット | `character-set` チェックボックスの `value` から取得 |

## 3. 処理設計

### 3.1 `randomBelow(max)`
1. 32ビット乱数の範囲を定義する。
2. `range - (range % max)` を上限とし、それ以上の値を再取得する。
3. 受理した値を `max` で剰余し、0以上`max`未満の整数を返す。
4. 乱数取得APIが使えない場合の処理は呼び出し側で事前確認する。

### 3.2 `generatePassword(length, selectedSets)`
1. 選択された各文字種の文字列を得る。
2. 各文字種から1文字ずつ選び、全選択文字種が含まれるようにする。
3. 選択文字種を結合したプールから、指定長になるまで文字を追加する。
4. Fisher-Yates方式で配列をシャッフルする。
5. 配列を文字列にして返す。

前提条件: `length` は選択文字種数以上であること。現在のUI制約（最小8、最大4種類）では満たされる。

### 3.3 生成フォーム送信
1. ブラウザー標準のフォーム送信を抑止する。
2. 結果欄を空にし、コピー操作を無効化する。
3. 長さ、選択文字種、安全な乱数APIの順に検証する。
4. 検証失敗時は対応するステータスを設定して終了する。
5. 生成関数を実行し、結果欄へ表示する。
6. コピー操作を有効化し、生成完了を通知する。

### 3.4 コピー操作
1. 結果欄が空なら何もせず終了する。
2. `navigator.clipboard.writeText` を呼び出す。
3. 成功時はコピー完了を通知する。
4. 失敗時は結果欄を選択し、手動コピーを案内する。

## 4. 状態とDOM対応

| 状態 | 結果欄 | コピー操作 | ステータス |
|------|--------|------------|------------|
| 初期 | 空 | 無効 | 空 |
| 検証エラー | 空 | 無効 | 入力エラーを表示 |
| 乱数API利用不可 | 空 | 無効 | 利用不可を表示 |
| 生成済み | 生成値 | 有効 | 生成完了 |
| コピー済み | 生成値 | 有効 | コピー完了 |
| コピー失敗 | 選択された生成値 | 有効 | 手動コピーを案内 |

## 5. エラー・境界条件

| 条件 | 処理 |
|------|------|
| 長さが整数でない、8未満、128超過 | 結果を消去し、生成を中止 |
| 文字種が未選択 | 結果を消去し、生成を中止 |
| `crypto.getRandomValues` がない | 結果を消去し、生成を中止 |
| Clipboard APIが拒否・失敗 | 例外を捕捉し、手動コピー手段を案内 |
| 生成前または空結果でコピー | コピー処理を行わない |

## 6. セキュリティ・プライバシー
- `Math.random` ではなく `crypto.getRandomValues` を利用する。
- 剰余バイアスを避けるため、乱数値を範囲内に棄却する。
- 各選択文字種を必ず含めた後、位置をシャッフルする。
- 生成値をログ、URL、サーバー通信、永続ストレージへ書き込まない。
- DOMへ表示する際はテキスト値として扱い、HTMLとして解釈しない。
- 将来、履歴・共有・解析を追加する場合は、生成値の取り扱いを要件・設計から再評価する。
